# MIPS — 4-bit MIPS Processor (Logisim)

A work-in-progress design of a reduced, **4-bit MIPS processor** built in [Logisim](http://www.cburch.com/logisim/) for the **CSE 210 – Computer Architecture Sessional** (BUET, July 2025 semester), lab group **B2, Group 4**.

## Design specification (from the assignment)

- **Address bus:** 8 bits
- **Data bus:** 4 bits, with a 4-bit ALU
- **Registers (4-bit):** `$zero`, `$t0`, `$t1`, `$t2`, `$t3`, `$t4`
- **Control unit:** microprogrammed, with control words stored in a ROM
- **Instruction length:** 16 bits
- Assembly programs are converted to machine code by an automatic assembler (any language)
- Memories: instruction memory (addressed by the PC), data memory, and an optional stack memory (bonus)

### Instruction formats

| Type | Bits 15–12 | Bits 11–8 | Bits 7–4 | Bits 3–0 |
|------|-----------|-----------|----------|----------|
| R-type | Opcode | Src Reg 1 | Src Reg 2 | Dst Reg |
| S-type | Opcode | Src Reg 1 | Dst Reg | Shamt |
| I-type | Opcode | Src Reg 1 | Src Reg 2 / Dst Reg | Address / Immediate |
| J-type | Opcode | Target address [7:4] | Target address [3:0] | 0 |

## Current progress

The circuit file currently contains these subcircuits:

- **`Instruction_Memory`** — a ROM (4-bit address, 16-bit data) that takes the `PC` as input and outputs the 16-bit instruction.
- **`main`** — top-level circuit wiring a `PC` input pin to the instruction memory and exposing the fetched instruction.
- **`Register`** — an empty placeholder for the register file.

The ALU, register file, data memory, microprogrammed control unit and assembler are not yet in this repository.

## How to open

1. Install [Logisim 2.7.1](http://www.cburch.com/logisim/) (or [Logisim-evolution](https://github.com/logisim-evolution/logisim-evolution), which can import 2.7.x files).
2. Open `B2_Grp-4.circ` via **File → Open**.
3. To load a program, right-click the ROM in `Instruction_Memory` → **Edit Contents…** and enter the 16-bit machine-code words.
